Wichtige Hinweise vor der Installation
======================================

Bitte schließen Sie vor dem Setup alle laufenden Instanzen von TimeTracker.
Falls Sie bereits Daten nutzen, legen Sie vorher am besten eine Sicherung an.

Die Anwendung speichert ihre Daten lokal auf diesem Computer unter
"C:\ProgramData\Kaltenmark-Engineering\TimeTracker".

Für die Installation sind in der Regel Administratorrechte erforderlich.
Auf der nächsten Seite werden Ihnen außerdem die Lizenzbedingungen angezeigt.

Drücken Sie auf "Weiter", um fortzufahren.
